v4 변경사항
1. API KEY REQUIRED 워터마크가 있던 CARTO 배경지도 제거, OpenStreetMap 기본 타일 사용
2. NIFS 관측소를 지도에 별도 표시
3. 양식장 선택 시 적용 관측소까지 점선 연결
4. 3시간 이상 지난 관측값은 양식장 매칭에서 자동 제외
5. 상세패널에 면허종류, 소유형태, 적정수온, 저/고온 한계 추가
6. 상단 수온 기준에 사용 관측소 수와 지연 제외 관측소 수 표시
7. 안전/주의/위험/미판정 현황 표시 개선

주의
- 노란색(주의)은 고온/저온 한계까지 2℃ 이내라는 HWANIAC 임시 운영 규칙이며 공식 경보 기준이 아닙니다.
- 현재 관측소 매칭은 '사용 가능한 관측소 중 직선거리 최단' 방식입니다. 해역/해안선 기반 매칭은 후속 개선 대상입니다.
