지도에서 양식장 마커를 클릭하면 면허정보, 최근 실시간 수온, 한계수온, 안전상태를 확인할 수 있습니다.

시도별 · 양식품종별 한계수온 현황

각 시도의 모든 양식품종을 펼쳐서 현재 적용수온과 한계수온, 안전상태를 함께 보여줍니다.

시도양식품종양식장 수현재 적용수온 평균적정수온저온 한계고온 한계안전주의위험미판정

현재 적용수온 평균은 각 양식장에 가장 가까운 NIFS 관측소의 이용 가능한 표층수온을 연결한 뒤 평균한 값입니다. 오래된 관측값도 값이 존재하면 사용하며 관측시각을 함께 확인할 수 있습니다. 표의 행을 클릭하면 해당 시도·품종으로 양식장 지도가 필터링됩니다.

한계수온은 수온별 노출기간, 어체크기, 건강상태, 사료섭취 및 사육환경 등에 따라 달라질 수 있습니다.

데이터 구성

면허정보업로드한 Excel의 면허정보·좌표정보를 사용합니다.
실시간 수온국립수산과학원 실시간 해양수산환경 관측시스템의 관측자료를 사용합니다.
매칭 방법각 양식장 좌표와 가장 가까운 NIFS 관측소의 표층 수온을 연결하고 관측소까지 거리를 표시합니다.
신호등운영 화면용 임시 규칙: 한계 초과=빨강, 한계까지 2℃ 이내=노랑, 그 외=녹색입니다. 관측값이 존재하면 관측시각과 관계없이 가장 가까운 관측소 값을 사용합니다. 한계수온이 없는 품종은 회색으로 표시합니다. 이 규칙은 공식 경보 기준이 아니며 조정 가능합니다.
실시간 API 업데이트

GitHub Actions가 NIFS API를 주기적으로 조회하여 data/risa-latest.json을 갱신하도록 구성합니다. API 인증키는 공개 코드에 넣지 않고 GitHub Actions Secret에 저장합니다.
